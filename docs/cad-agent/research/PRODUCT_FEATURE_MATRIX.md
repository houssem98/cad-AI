# Product Feature Matrix

L1 T1, read 2026-11-08 from the reference's public pages only: the homepage (https://mecagent.com/) and the single-page user guide (https://mecagent.com/user-guide). Nothing was observed in the app yet; T5 adds `chain:` cells and T8 upgrades labels from runtime and walkthrough evidence.

Every cell is our own wording. Source quotes are verbatim and kept under 12 words. The label column is CONFIRMED when a public page states the module's core behaviour. Details marked "(unverified)" come from the fetcher's summary of the guide's second half, not from verbatim page text. "Not described" means the public pages say nothing about it.

## Cross-cutting facts

- CAD host: SolidWorks is the only native target, tested on 2024, 2025 and 2026; older versions are not guaranteed. Other CAD systems (Inventor, CATIA V5, NX, Creo, Solid Edge, Fusion 360, Onshape) are listed as coming. Without SolidWorks, users are pointed at Background Tasks with STEP output.
- Platform: a Windows 10 or 11 64-bit desktop app in its own window next to SolidWorks, plus a web app for drawing projects. Mac is not mentioned.
- Stated limits: no release without engineering review, no certification guarantees, no class-A surfacing from vague text, no building from ambiguous instructions without dimensions, and company rules only when supplied.
