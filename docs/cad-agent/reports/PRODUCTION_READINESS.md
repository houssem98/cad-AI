# Production Readiness

L8 T1, written 2026-11-14. One row per module of `docs/cad-agent/research/PRODUCT_FEATURE_MATRIX.md`, with a capability word from `docs/LOOP_CONVENTIONS.md` (I11) and the tests that back it, cited as `path#literal`. `scripts/readiness-lint.mjs` fails when a module has no row, a word is not one of the five, or a row that is not UNTESTED or UNSUPPORTED cites no test.

No module is PRODUCTION READY. The roadmap's rule is `docs/roadmap/MECAGENT_ROADMAP.md#Do not declare the product production-ready merely because the frontend and API tests pass.` Every capability below runs on the headless build123d kernel in a local server, not inside SolidWorks (L9 waits on a licence), with one model (DeepSeek), and the gate replays recorded model responses.
